고등학교 생활 3월 부터 다음해 3월까지 고3기간을 지정

스탯
1.힘(근력) -> 무거운물건옮기기,싸움,힘이필요한능력에 전반적으로 이용됨
2.매력(교우관계에 영향)
3.지능(시험점수에 관련) -> 지능대신에 플레이어가 직접 문제를 풀게한다면 -> ex)1~10=고급문제 11~20=중급문제 21~30=초급문제
4.체력(특정행동에사용)

특수스탯
1.운(시험에서 찍어서맞출확률증가,랜덤이벤트발생가능성)
2.반항심(나쁜짓하기)

주요 컨텐츠
1.성적관리
2.멘탈관리
3.교우관계
4.욕?구?관리
