## 주요 컨텐츠
- 성적관리 -> 중간고사 기말고사 모의고사 후에 고3에 존재하는 수능까지 지능을올려서 쉬운문제를풀고 점수를 잘받던지 지능이낮아서 어려운문제를 풀지 관리
- 멘탈관리  -> 너무 공부만하면 번아웃등의 현상으로인해 일정에 문제가 생김
- 교우관계 -> 친구가없으면 왕따를 당하거나 여러 학교이벤트에서 불이익을받을수있음
- 욕?구?관리 -> 기본적인 욕구 관리 시스템 근데 있으면 좀 귀찮긴할듯
- 학교졸업 -> 학교 졸업 방법은 여러가지 원하는대학을 진학하거나 재수하거나 처럼 결국 학교졸업이 엔딩임
  - 퇴학 -> 학교생활중 사고치거나 특정행동으로 (가칭)벌점이 너무많이쌓이면 학교에서 퇴학당할수있음 원래는 게임오버가 맞지만 이것또한 엔딩에 한종류
- 학교생활,학교에서 발생할수있는 이벤트들 -> 시험부터 시작해서 체육대회,수학여행,여러가지대회 같은것들이발생
