# jinu_grow
하이하이 로크만

탑 등반하면서 다키스트마냥 영웅 고용하고 고용한영웅들을 탑에 보내서 전투시키고 탑을 정복하는게 목적

영웅들은 특정조건을달성하면 전직이 가능함
ex) 전사->기사 이런식으로

전투는 trpg처럼 20면체 주사위굴려서 1:대실패 20:대성공 나머지는 값에 맞춰서 전투진행


탑뷰 보드게임? 횡스크롤 형식 겜?

둘다 괜찮은데 일단 두개다 생각해보겠음

------------------------------
어느날 탑이 생기고 탑에서부터 시작되는 몬스터웨이브를 막기위해 주인공이 탑을 오르기시작함

몬스터웨이브를 막기위해서는 탑의보스가 되어야만 하는 운명임

왜 몬스터웨이브를 막으려면 탑의 보스가 되어야하는가?
탑의 보스가 없기때문에 몬스터들이 억제되지않아서 몬스터웨이브가 일어나게되는이유임 탑의 보스가 왕으로서 몬스터를 막는느낌

그렇다면 주인공은 왜 탑의 보스가 되어야하는가?
주인공을 제외한 다른 인물이 탑의 보스가 될수도있는거아닌가?
